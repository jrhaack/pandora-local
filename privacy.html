Privacy Policy

Pandora Local · last updated 13 September 2026

Pandora Local is a personal application used by a single person — its owner — on their own computer. It has no other users, no accounts and no server. This policy describes how it handles data.

What data it handles

  • Lecture recordings and transcripts created by the owner, read from a folder on the owner's computer.
  • Study notes generated from those transcripts and saved to a local notes folder on the same computer.
  • Google Calendar events — read only, to determine which class session a recording corresponds to.
  • Google Tasks — to create and update the owner's own coursework reminders.

Where data goes

Everything stays on the owner's computer. Transcription and note generation run locally using models installed on that machine. No lecture audio, transcript or generated note is transmitted to any cloud AI provider, analytics service, advertiser or other third party.

The only network requests the application makes are to Google's own APIs, on the owner's behalf and with the owner's consent, for the two purposes above.

Google user data

The application requests two scopes: calendar events, and tasks. Calendar data is used only to identify class sessions. Tasks data is used only to create and update the owner's coursework reminders. Neither is used for any other purpose, shared with anyone, sold, or used to train any model.

Pandora Local's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and retention

Google access tokens are stored in a private, permission-restricted file on the owner's computer and nowhere else. Recordings, transcripts and notes remain on that computer until the owner deletes them. There is no remote copy and no backup managed by this application.

Revoking access

Access can be withdrawn at any time from Google Account permissions. Deleting the local token file has the same effect for this application.

Children

The application is not directed at children and is used only by its adult owner.

Changes

If this policy changes, the revised version will be posted on this page with a new date.
