Pandora Local

A personal study-notes tool that runs on one Mac.

Pandora Local turns recorded college lectures into study notes. It is a private tool built and used by one student for their own coursework. It is not a product, it is not offered to other users, and it has no accounts, no server and no sign-ups.

What it does

  • Reads lecture recordings and transcripts that already exist on the computer.
  • Writes study notes into a local Obsidian folder on that same computer.
  • Reads the owner's Google Calendar to work out which class a recording belongs to.
  • Creates reminders in the owner's Google Tasks for coursework and deadlines.

Where the processing happens

Transcription and note writing run entirely on the local machine using local models. No lecture audio, transcript or note is sent to any cloud AI service or any third party.
